# BrainFart

A real-time multiplayer trivia game built with Next.js, Socket.io, and Prisma.

## Features

- Multiplayer trivia rooms
- Real-time gameplay with Socket.io
- User authentication (Better Auth)
- Leaderboards and rankings
- Question submission system

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play.

## Tech Stack

- Next.js 15+ (App Router)
- TypeScript
- Tailwind CSS v4
- Prisma ORM
- Better Auth
- Socket.io
- Zustand
